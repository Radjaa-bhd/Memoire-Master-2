# Mémoire de Master 2

Ce dépôt rassemble les données, les traitements et les résultats produits dans le cadre de mon mémoire de Master 2 consacré à la représentation des femmes dans les récits de voyage arabes et français.

Ce travail croise analyse littéraire et humanités numériques afin d’étudier la manière dont les voyageurs décrivent les femmes rencontrées dans des sociétés différentes de la leur. L’objectif est de partir des données pour revenir aux textes et mieux comprendre ce que les mots employés autour des figures féminines nous disent du regard porté sur l’autre.

## Contenu du dépôt

Le dépôt suit les différentes étapes de ce travail :

- `corpus_francais/` : les six récits du corpus français au format TXT.
- `corpus_arabe/` : les quatre récits du corpus arabe au format TXT.
- `scripts/` : les scripts et notebooks utilisés pour le traitement et l’analyse des corpus.
- `resultats/annotations_automatiques/` : les résultats de l’identification automatique des figures féminines dans le corpus français.
- `resultats/annotations_manuelles/` : les annotations manuelles réalisées pour le corpus arabe.
- `resultats/concordanciers/francais/` : les concordanciers du corpus français.
- `resultats/concordanciers/arabe/` : les concordanciers du corpus arabe.

Les concordanciers rassemblent chaque figure féminine avec les dix tokens qui précèdent et suivent la mention, ainsi que la phrase complète dans laquelle elle se trouve. Ils servent de point de passage entre les résultats quantitatifs et le retour aux textes.

Ce dépôt accompagne ainsi le mémoire et garde une trace des différentes étapes de la recherche, depuis la constitution et le traitement des corpus jusqu’aux données utilisées dans l’analyse.
