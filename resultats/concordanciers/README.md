# Concordanciers

Ce dossier contient les concordanciers construits à partir des figures féminines identifiées dans les corpus français et arabe.

Pour chaque figure féminine, le concordancier contient :
- la figure féminine identifiée ;
- les 10 tokens précédant la mention ;
- les 10 tokens suivant la mention ;
- la phrase complète dans laquelle la figure féminine est mentionnée.

Dans la phrase complète, la figure féminine étudiée est indiquée entre parenthèses afin de faciliter son repérage dans le contexte.

Les concordanciers sont séparés en deux dossiers : `francais` et `arabe`.
