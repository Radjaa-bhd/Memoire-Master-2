# Concordanciers du corpus arabe

Ce dossier contient les concordanciers des quatre récits du corpus arabe.

Les concordanciers ont été construits à partir des figures féminines identifiées lors de l’annotation manuelle du corpus arabe.

Pour chaque occurrence, le concordancier contient la figure féminine identifiée, les 10 tokens précédant la mention, les 10 tokens suivant la mention et la phrase complète dans laquelle elle se trouve.

Dans la phrase complète, la figure féminine étudiée est indiquée entre parenthèses afin de faciliter son repérage dans le contexte.
